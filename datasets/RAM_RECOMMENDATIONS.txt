================================================================================
                         RAM CALCULATION FORMULA
================================================================================

HNSW Index Memory ≈ vectors × dim × 4 bytes × (1 + M/16)

Where:
  - vectors = number of vectors
  - dim = vector dimension  
  - 4 bytes = float32
  - M = HNSW parameter (16, 32, or 64)

Example for glove-100-angular with M=32:
  1,183,514 × 100 × 4 × (1 + 32/16) = 1,420 MB ≈ 1.4 GB (just vectors)
  + HNSW graph overhead (~50-100%) = 2.1-2.8 GB total

================================================================================
                         SAFETY TIPS
================================================================================

1. BEFORE HEAVY DATASETS:
   - Stop all other Docker containers
   - Close Chrome/browser tabs
   - Check: free -h (should show 20GB+ available)

2. MONITOR DURING BENCHMARK:
   - Watch: docker stats
   - If RAM > 90%, STOP and reduce parallel uploads

3. IF OUT OF MEMORY:
   - Reduce upload_params.parallel from 16 to 8
   - Reduce search_params.parallel from 100 to 50
   - Run datasets one at a time

4. SKIP IF NECESSARY:
   - gist-960-euclidean (3.6GB download, 10GB RAM)
   - dbpedia-openai-1M-1536-angular (6GB download, 12GB RAM)
   These are optional - you have enough variety without them!
